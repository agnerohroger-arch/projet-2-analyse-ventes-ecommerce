
# Projet 2 — Analyse des ventes d'un site e-commerce

## Contexte
Projet réalisé dans le cadre de ma formation Data Analyst chez OpenClassrooms.

L'objectif est d'analyser les performances commerciales d'un site e-commerce afin d'identifier les tendances de ventes et de proposer des recommandations pour améliorer les résultats.

## Problématique métier
Comment analyser les ventes d'un site e-commerce pour comprendre les performances commerciales et améliorer la prise de décision ?

## Méthodologie
1. Exploration et préparation des données de ventes.
2. Analyse du chiffre d'affaires et de son évolution.
3. Étude des performances par catégorie de produits.
4. Analyse des clients affiliés et des indicateurs clés.
5. Présentation des résultats et recommandations commerciales.

## Compétences mobilisées
- Analyse de données
- Excel
- Indicateurs clés de performance (KPI)
- Analyse commerciale
- Data Visualisation
- Reporting

## Livrables
- Rapport mensuel d'analyse des ventes (PDF)
- Fichier Excel d'analyse des clients affiliés (XLSX)
